# POS Tec

Este proyecto será un **POS (Punto de Venta)** básico para pequeños negocios,
hecho únicamente con HTML.

## ¿Qué es un POS?

Un POS (Point of Sale) es el sistema que usa un negocio para registrar sus ventas:
agregar productos al carrito, calcular el total, cobrar y entregar un ticket.

## Contenido

El archivo `index.html` incluye:

- Página de bienvenida
- Catálogo de productos con stock
- Carrito de compra con subtotal, IVA y total
- Datos del cliente y método de pago
- Reporte de ventas del día
